# Changelog

All notable changes to this project will be documented in this file.

## [0.1.1] - 2026-08-24

- Add `install.sh` script to build and install the CLI
- Document install and uninstall instructions in `README.md`
- Sort and clean up README sections

## [1.2.0] - 2026-08-24

- Add `install.sh` support for `--tag` and `--archive-url` to install specific releases
- Add curl+pipe install examples to `README.md`
- Improve installer fallback behavior when run outside a checkout


## [0.1.0] - 2026-08-24

- Initial release: TypeScript CLI wrapper for `phpcs` and `drupal-check`
- Added build (`npm run build`) and `bin` entry pointing to `dist/cli.js`
